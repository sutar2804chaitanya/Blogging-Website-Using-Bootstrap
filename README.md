# 🛒 ShopStart E-Commerce Website

A responsive and modern **E-Commerce Website UI** developed using **Bootstrap 5.3** as part practical assignment.

The project demonstrates the use of Bootstrap components such as navigation bars, carousels, cards, badges, and modals to create an attractive online shopping interface.

---

## 📌 Project Information

* **Practical:** Design Website Using Bootstrap
* **Project Title:** ShopStart E-Commerce Website
* **Technology Used:** HTML5, Bootstrap 5.3

---

## 🚀 Features

### ✅ Responsive Navigation Bar

* Brand logo (ShopStart)
* Home and Shop navigation links
* Shopping cart with item count badge

### ✅ Hero Carousel

* Promotional banner slider
* Summer Sale advertisement
* New Arrivals showcase

### ✅ Featured Products Section

Displays product cards with:

* Product image
* Product title
* Description
* Price
* Action buttons

### ✅ Product Badges

* 🔥 HOT Product Badge
* 🆕 NEW Product Badge

### ✅ Quick View Modal

Interactive popup displaying:

* Product image
* Product details
* Features list
* Product price
* Add to Cart button

### ✅ Bootstrap Components Used

| Component   | Purpose                   |
| ----------- | ------------------------- |
| Navbar      | Website navigation        |
| Carousel    | Promotional banners       |
| Cards       | Product display           |
| Badges      | Product status indicators |
| Modal       | Product quick view        |
| Buttons     | User actions              |
| Grid System | Responsive layout         |
